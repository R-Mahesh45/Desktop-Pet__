# 🐾 Desktop Pet & Break Reminder

A lightweight, interactive PySide6 desktop companion designed to make your workday fun while reminding you to take healthy breaks.

![Desktop Pet Banner](assets/icon.png)

---

## ✨ Features

- 🤸 **Spontaneous Behaviors**: Dynamic walking, mid-walk hops, kicks, crouches, and physics-based drag-and-drop mechanics.
- 💧 **Smart Break Reminders**: Customizable wellness alerts (hydration, eye rest, stretching).
- 🖥️ **Display & Multi-Monitor Aware**: Automatically detects display boundaries, stays above taskbars, and supports multi-monitor setups.
- 📌 **Always On Top**: Native Windows `HWND_TOPMOST` z-ordering ensures your pet stays visible over active applications.
- 🔒 **Single-Instance Control**: Crash-resilient single process enforcement (`QLockFile`).
- 🌙 **Sleep / Pause Mode**: Quickly pause reminders and animations when you need focus time.
- ⚙️ **User Settings**: Customize break frequency, popup duration, custom messages, and Windows auto-start options.

---

## 🚀 Installation & Download

### Windows Installer (Recommended)
1. Download `DesktopPet_Setup.exe` from the [Releases](https://github.com/your-username/desktop-pet/releases) section.
2. Run the installer and follow the setup wizard.
3. Launch `Desktop Pet` from your Desktop or Start Menu!

---

## 🎮 How to Interact

| Interaction | Action |
| :--- | :--- |
| **Left-Click & Drag** | Pick up and toss your pet |
| **Left-Double-Click** | Make your pet jump |
| **Right-Click** | Open context menu (Pet me, Sleep, Settings, Switch Character, Quit) |
